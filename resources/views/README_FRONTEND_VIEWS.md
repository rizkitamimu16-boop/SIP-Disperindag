# [FRONTEND] DIREKTORI TEMPLATE VIEW BLADE

Folder ini adalah **FRONT-END AREA**:
Berisi seluruh berkas Blade template yang merender antarmuka pengguna:
- `admin/` : Tampilan halaman Panel Administrator (Data Pegawai, Presensi, Kegiatan, Pengajuan, Kinerja, SP, Pengaturan).
- `pegawai/` : Tampilan halaman Panel Pegawai PPPK (Dashboard mobile, Absensi, Lapor Kegiatan, Izin/Cuti, Kinerja, Profil).
- `auth/` : Halaman formulir masuk (login) sistem.
- `layouts/` : Kerangka induk tata letak (`admin.blade.php`, `pegawai.blade.php`).
- `components/` : Modal dialog pop-up, preview lampiran, dan skrip JavaScript pendukung.
