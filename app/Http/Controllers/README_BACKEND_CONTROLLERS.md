# [BACKEND] DIREKTORI CONTROLLER & LOGIKA BISNIS

Folder ini adalah **BACK-END LOGIC AREA**:
Berisi controller yang mengendalikan alur logika sistem, validasi formulir, dan interaksi ke model database:
- `Admin/` : Controller untuk panel Admin (CRUD pegawai, monitoring presensi, approval dispensasi izin, penilaian kegiatan harian, konfigurasi kantor).
- `Pegawai/` : Controller untuk panel Pegawai (pencatatan presensi GPS geofencing, submit laporan kegiatan, pengajuan permohonan izin/cuti).
- `Auth/` : Controller autentikasi login, validasi kata sandi, dan proteksi sesi.
